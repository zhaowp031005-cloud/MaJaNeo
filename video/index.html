Grok Bot × Claude Code 操作总览
截图保存
1

下载并登录

  • 官方下载页 x.ai/bot 下载桌面版并登录
  • 套餐：Premium / Super / Ultra 含 Grok Bot 额度（Plus 不含）
  • 按用量按需充值，可用 支付宝
  • 前提：能正常访问官方下载页和登录页
2

建子 agent 装 CC

  • 新建子 agent「Claude Code 助手」，CC 相关任务都交给它
  • 发安装指令：只在它的云端 Linux 电脑上装，先 claude --version 检查
  • 显示版本号 = 已装好（≠ 已登录）
3

登录并授权

  • 先用 Gmail 注册 Claude 账号
  • 让 CC 助手启动 Claude Code 登录流程
  • 浏览器授权你来接管，登录码粘回终端，不发进聊天
  • 看到 Login successful 交还 Bot
4

第一次调用

  • 让 Bot 通过终端调用 CC 助手的 Claude Code，不要代写
  • 在空目录 /workspace/cc-demo 建测试页
  • 只改项目目录，不跳过权限检查
  • 收到 截图 + 按钮测试 + 文件清单 = 跑通
日常使用说清楚：调用 Claude Code
+ 这次允许改哪些文件
排错登录提示 → 先查授权状态 claude auth status
额度用完 → 分清 Grok Bot / CC 两套额度
别一报错就重复安装
注意云端运行 ≠ 账号免封
Claude 账户与地区规则仍适用
以上命令都在 Bot 的云端电脑上运行，不在你自己的电脑上
